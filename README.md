# QR_Pro v.1.0
Консольный генератор QR-кодов для Windows. Python 3.10+.
Автор Кочарян Артём Евгеньевич и Codex

## Запуск
В текущей среде зависимости уже помещены в .deps:
```
python run.py
```
Для установки на другом компьютере:
```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```
## Работа
1. Введите текст через пункт 1.
2. При необходимости измените параметры через пункт 2. Версия: Enter для автоматического выбора, размер: 1–50, коррекция: L/M/Q/H. Цвета: #RRGGBB.
3. Пункт 3 сохраняет PNG. Enter выбирает папку output и автоматическое имя. Совпадения имён получают индекс.
4. Для пакетной обработки выберите пункт 4 и файл examples/batch.txt. Одна строка — один QR. Пустые строки пропускаются, пробелы в непустых сохраняются. Файл должен иметь кодировку UTF-8, BOM допускается.
5. Пункт 0 завершает работу.

Лог: qr_pro.log рядом с программой. Содержимое QR в лог не записывается.
Низкий контраст сопровождается предупреждением. Произвольные цвета и слишком мелкие модули могут ухудшить считывание; для надёжности используйте тёмный код на светлом фоне.

## Отладка
```
python -m unittest -v test_qr
```
Примеры: URL https://example.org, строка «Привет, мир!», пробельный ввод, версия 1 с длинным текстом, повторное сохранение под тем же именем, недоступная папка, неверный цвет #ZZ0000.
Проверьте сохранённые PNG камерой телефона: результат должен точно совпадать с исходным текстом, включая пробелы. Это ручная проверка; автоматического декодера в комплекте нет.

В пакетном режиме Enter на запрос пути выбирает examples/batch.txt рядом с программой. Ввод текста в пункте 1 не влияет на пакетный режим. Enter на запрос папки сохраняет PNG в output рядом с программой.
